# 🧠 Welcome to KP-Lang Core

> The Legacy Voice-AI Programming Language

KP-Lang is an open-source, multi-language, AI-enabled programming language designed to make coding as easy as speaking. Whether you're automating hardware, scripting AI workflows, or bridging Python with C, KP-Lang helps you speak your logic into action.

---

## 🚀 Getting Started

### 📦 Install KP-Lang (Coming Soon)
```bash
git clone https://github.com/kplang/kplang-core.git
cd kplang-core
python3 kp.py run examples/hello.kp
```
